# 90-day gated growth plan

The schedule is a maximum pace, not permission to bypass G0–G6. The owner may pause or stop at any time.

## Days 1–14: trust foundation

- Complete G0: name owners, approved accounts, platform rules, data boundaries, and incident/stop procedure.
- Complete G1: run `npm test` and `npm run validate`; audit README examples and local links against `main`.
- Build one MVTA using a temporary destination and capture sanitized commands, expected files, limitations, and recovery.
- Interview or review feedback from at least five relevant users without harvesting private data.

Exit only when the validator is green and an independent reviewer reproduces the MVTA.

## Days 15–30: message fit

- Complete G2 and G3: select one audience, one problem, and one evidence-backed outcome.
- Draft three message angles: safe preview, Codex-native package, and starter-kit evaluation.
- Review every claim in the evidence ledger. Remove vanity counts and unverified performance claims.
- Prepare accessible media and plain-text alternatives; do not publish yet.

Exit when reviewers can distinguish each distribution and repeat the safe two-step flow.

## Days 31–60: small experiments

- Complete G4 before each experiment.
- Human-post no more than one original post per selected community in a seven-day window.
- Answer questions manually. Do not coordinate votes, repost identical copy, or send unsolicited DMs.
- Capture aggregate outcomes and qualitative feedback using the measurement spec.

Advance through G5 only when moderation signals, corrections, and user feedback show the experiment is welcome and accurate.

## Days 61–90: deepen or stop

- Improve the MVTA, setup recovery, or starter-kit docs based on repeated user friction.
- Publish a changelog-style follow-up only when there is material new evidence.
- Compare qualified engagement and successful reproductions with the baseline.
- Complete G6: continue one useful format, revise one, and explicitly stop ineffective or harmful tactics.

## Stop conditions

Pause immediately for a security disclosure, leaked data, misleading claim, platform warning, moderator request, harassment pattern, or unexpected external action. Correct affected material and document the decision before resuming.
