| Goal | Canonical guide |
|---|---|
| Understand the project | [README.md](./README.md) |
| Preview a generic workspace install | [setup.md](./setup.md) |

Do not copy or symlink the full `skills/` directory into a live harness. Start with a focused kit and follow [setup.md](./setup.md), the single maintained source for generic preview, apply, update, and recovery commands.

Legacy OpenClaw layouts are repository history, not the current recommended installation path. Never infer provider credentials, gateway configuration, or runtime compatibility from the presence of a manifest.
