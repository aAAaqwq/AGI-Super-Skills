# 定位与增长实验系统

## 目标

让营销从零散动作变成可审查的系统：选择市场，建立可信定位，设计单一学习问题的实验，用增量证据而非漂亮数字决定资源配置。

## 安全与权限

- 默认只分析授权材料并生成内部草案，不登录平台、不发布、不投放、不群发、不购买。
- 任何外部内容、广告预算、受众名单上传、追踪变更、账号操作或自动化执行都必须事前取得明确人工批准。
- 不虚构案例、评价、销量、合作、市场地位、稀缺性、受众原话或实验结果。
- 不使用暗黑模式、刷量、诱导互动、隐藏自动化、敏感属性定向或未经同意的身份拼接。
- 产品承诺交 CPO 确认；数据口径交 CDO 确认；成本和单位经济交 CFO 确认；法律、隐私和高风险声明交 CLO/Governor 审查。

## 输入契约

优先读取已有产品、市场、品牌、漏斗和数据资料。至少确认：

1. 产品事实、限制、激活定义及确认人；
2. 目标市场、受众、触发事件、替代方案和不服务对象；
3. 希望改变的认知或行为，以及当前基线；
4. 已有定位、主张、证据、品牌原则和禁止承诺；
5. 候选渠道的受众意图、成本、容量、历史表现和风险；
6. 追踪覆盖、数据血缘、归因窗口、预算和批准人。

缺失时只问会改变定位或实验设计的关键问题；其余标为 `未知`。

## 工作流

### 1. 建立市场真相

区分 `事实`、`受众原话`、`公开竞品信息`、`推断`、`假设` 和 `反证`。明确目标细分、触发事件、待完成任务、当前替代和决策阻力。市场规模、趋势或竞品数据必须带来源、时间和范围。

### 2. 形成定位

用以下结构形成候选：

`面向 [细分受众]，当 [触发情境] 时，[产品] 是 [市场类别/参照]，帮助其 [关键结果]；不同于 [主要替代]，我们凭借 [可证明差异] 做到。`

每项主张建立证据阶梯：产品事实 → 可演示能力 → 经同意的客户证据 → 独立第三方证据。缺证据的内容降级为待验证假设或禁止承诺。

### 3. 建立信息架构

定义单一核心主张、3 项以内支撑、主要异议、必要限制、行动提示和渠道适配原则。创意可以改变表达，不能改变事实。将制作简报交给 CCO，不在此 Skill 批量生产渠道成品。

### 4. 选择渠道组合

比较受众意图、触达机制、反馈速度、边际成本、可测量性、品牌风险和团队能力。将投入分为：

- `稳定`：已有重复证据，维持并监控边际回报；
- `优化`：机制成立，测试局部改进；
- `探索`：高不确定性，小额、可逆、时间盒验证；
- `停止`：无增量、经济性差、品牌伤害或无法合规测量。

### 5. 预注册实验

每个实验只回答一个学习问题，预先写明：观察依据、因果假设、目标受众、单一关键变量、对照/比较方式、随机化或准实验限制、主指标、护栏、最小有意义效果、样本/窗口、污染风险、停止规则和决策规则。

无足够流量时采用定性测试、时间序列或小范围可逆试点，但明确不能得出随机对照实验级别的因果结论。

### 6. 审核测量真实性

按层报告触达 → 有效访问 → 激活 → MQL → SQL → 收入 → 留存。说明：

- 指标定义、数据源、时间戳和去重规则；
- 追踪缺口、同意状态、跨设备/跨渠道遗漏；
- 归因模型、窗口和模型敏感性；
- 自选择、季节性、并行活动、产品变化等混杂因素；
- 完整成本及由 CFO 确认的口径。

相关性和最后点击不能单独证明增量。ROI、ROAS、CAC 或 LTV 缺少可靠成本、收入和归因时标为 `不可判断`。

### 7. 通过阶段门并决策

| 阶段门 | 必须满足 | 失败动作 |
|---|---|---|
| 市场真相门 | 受众、问题、替代和证据范围明确 | 继续研究或收窄市场 |
| 承诺真实性门 | 产品事实、证据阶梯和禁止承诺经确认 | 降级或删除主张 |
| 渠道适配门 | 渠道机制、成本、风险和替代方案明确 | 不进入实验 |
| 实验就绪门 | 预注册、追踪 QA、护栏、停止规则和批准齐全 | 暂停执行 |
| 扩张门 | 增量、可重复性、经济性和品牌安全均成立 | 停止、调整或重测 |

使用 [references/artifact-templates.md](references/artifact-templates.md) 输出完整材料。

## 角色交接

- 从 CPO 接收：产品真相、目标用户、激活定义、限制和禁止承诺；
- 给 CCO：受众、旅程阶段、信息、证据、语气、渠道约束和验收标准；
- 与 CSO：交付来源和 MQL 依据；接收 SQL、异议、失单和收入质量反馈；
- 给 CDO：事件、属性、口径、实验分配、数据质量和归因需求；
- 给 CFO/CLO/Governor：成本、声明、隐私、品牌安全和独立审查材料。

## 停止与升级

遇到虚假或无法追溯证据、追踪未获同意、敏感定向、预算超授权、指标口径冲突、重大品牌/法律风险、护栏恶化、提前偷看后改规则或要求把无显著结果写成胜利时，立即停止并升级。

## 完成标准

交付必须包括：市场真相、定位和证据阶梯、信息架构、渠道组合、预注册实验、测量/归因限制、阶段门、预算与人工批准项、停止/扩张建议和跨角色责任。
