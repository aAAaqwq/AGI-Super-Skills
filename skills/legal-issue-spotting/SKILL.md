# 法律问题识别

提供一般性法律问题识别与决策支持，不构成法律意见，不建立律师—客户关系或律师保密特权。重大事项必须由相关司法辖区的合格律师复核。

## 确定是否适用

用于识别问题、组织事实、定位权威、比较风险选项和准备专业交接。若任务只是逐条合同红线，配合合同审查 Skill；若用户要求正式意见、代理、签署、提交或结果保证，停止并转交合格专业人士。

## 收集最小 intake

确认：

- 主体、法律身份和授权关系；
- 行为发生地、目标市场、签约地、数据/人员所在地和可能司法辖区；
- 发生了什么、何时发生、谁受到影响；
- 业务目标、金额/影响、期限和可逆性；
- 当前文件版本、数据/资产类别、争议事实和缺失材料；
- 是否已有当地律师及其复核范围。

不得猜测缺失事实或辖区。用 `FACT`、`ASSUMPTION`、`DISPUTED`、`UNKNOWN` 分开记录。

## 工作流

### 1. 建立事项边界

用一句话描述主体、行为、地点、时间和目标。列出不在本次范围内的问题，避免一般原则被误用到其他主体或地区。

### 2. 绘制关系与权利义务

识别合同方、消费者、员工/承包商、数据主体、平台、权利人、监管者和第三方。说明谁向谁作了承诺、处理何种数据或使用何种资产。

### 3. 生成问题树

仅选择被事实触发的领域：

- 合同成立、授权、履行、付款、保证、赔偿、责任、终止和争议；
- 隐私、数据角色、合法基础、告知、同意、保留、安全和跨境；
- 著作权、商标、专利、商业秘密、肖像、开源和生成式内容权利；
- 消费者保护、广告主张、赞助披露、退款和平台规则；
- 劳动/承包关系、公司治理、税务接口、贸易或监管许可。

不因关键词出现就断言适用；把“为何可能触发”写清楚。

### 4. 区分权威层级

分别记录法律法规、监管规则、官方指引、判例、合同条款、行业标准、平台政策和最佳实践。引用可定位的官方或权威来源，并写明司法辖区、生效日期、版本和访问日期。

模板、博客、搜索摘要和模型记忆只能作为线索，不得冒充权威。不得虚构法条、判例、监管意见、许可、认证或律师复核。

### 5. 应用规则到事实

逐项使用：问题 → 规则/权威 → 触发事实 → 支持与反对分析 → 初步结论 → 缺失事实。存在冲突法、解释分歧或执法差异时，呈现分歧，不制造唯一答案。

### 6. 分级并设计选项

综合可能性、影响、可逆性、时间紧迫性和可发现性：

- `CRITICAL`：刑事、人身、政府禁令/调查、重大不可逆责任或立即期限；停止并升级。
- `HIGH`：重大财务、数据、知识产权、雇佣或声誉后果；当地律师复核后再承诺。
- `MEDIUM`：可通过条款、流程或技术控制缓解；记录残余风险。
- `LOW`：影响有限且可逆；仍记录前提与复核日期。

为每项问题比较修改、控制、转移、接受或停止方案，写明成本、负责人、时限和残余风险。风险等级不是“合法/违法”结论，也不代表已经接受。

### 7. 形成控制与证据链

将义务映射为控制、负责人、频率、证据、缺口和复核日。合规不是一次文档或检查标签。

### 8. 准备专业交接

向当地合格律师提供精确问题、事实时间线、关键文件索引、内部目标、备选方案、期限和希望确认的结论。只保存必要摘要，不扩大敏感材料访问面。

## 质量门

1. 主体、辖区、行为和日期明确；
2. 事实、假设、争议和未知分开；
3. 关键规则来自可定位且时效匹配的权威；
4. 规则要件与事实逐步对应；
5. 风险、选项、控制、残余风险和负责人齐全；
6. 专业复核范围与不能回答的问题醒目标记。

```markdown
## 关系与权利义务图

```

## 立即停止与升级

诉讼、政府调查、刑事或人身风险、重大责任、股权融资、税务结构、跨境数据、雇佣终止、监管申报、知识产权归属争议、即将到期的权利，或司法辖区不明的高影响事项，立即升级给授权人类和相应专业人士。

任何签署、发送、备案、监管联系、账号访问或外发敏感文件均需事前明确人类批准，并由有权人员执行。合同财务影响交 CFO，数据流交 CDO/CTO，内容与广告主张交 CCO/CMO，控制落地交 COO。
