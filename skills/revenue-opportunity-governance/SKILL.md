# 销售机会治理

## 目标

提高机会真实性和可交付收入质量。让每次阶段推进都有客户侧证据，让每项承诺都有内部负责人批准，让成交自然进入客户成功闭环。

## 安全与权限

- 默认只分析用户提供或授权的脱敏材料并生成内部草案。
- 不发送邮件/消息、不拨号、不群发、不录音、不抓取联系人、不登录或写入 CRM、不创建日历事件。
- 不报价、不批准折扣、不发送提案、不修改合同、不签约、不承诺功能、交期、价格、条款或结果。
- 任何外部联系、CRM 写入、录音、报价、折扣、提案发送、合同或账号操作都必须逐项取得明确人工批准。
- 不虚构客户原话、预算、权限、阶段、概率、案例、合同状态或收入。
- 最小化客户数据：使用机会代号和角色，只保留当前决策需要的信息。

## 输入契约

优先读取已授权的机会材料。至少确认：

1. ICP、触发事件、排除条件和线索来源/同意状态；
2. 客户确认的问题、影响、现有替代和改变代价；
3. 使用者、影响者、批准者、采购、预算和风险角色；
4. 决策标准、决策流程、时间条件和双方投入；
5. 产品范围、技术/交付、价格和条款的内部确认状态；
6. 当前阶段、客户侧证据、下一步、风险和预测窗口。

信息不足时不得用默认概率填空。标记缺口并说明其对阶段或预测的影响。

## 证据分类

- `客户确认`：可追溯的客户表达或客户侧行动；
- `内部确认`：产品、交付、价格或条款由有权负责人批准；
- `销售推断`：合理但尚待验证；
- `未知`：缺少且可能改变决策；
- `反证`：与机会假设或当前阶段冲突；
- `阻塞`：缺关键角色、批准、信息或双方行动。

不得把卖方活动量当客户意向，不得把自动化系统字段当独立证据。

## 工作流

### 1. 发现真实问题

围绕现状、问题、频率、业务影响、现有替代、已尝试方案、改变代价和成功标准准备少量开放问题。发现目标是理解，不是逼迫客户承认痛点。保留客户原话与情境，销售解释单列。

### 2. 资格判断

判断以下条件是否成立：

- 问题足够重要且适合当前产品；
- 客户有清晰价值和改变理由；
- 决策角色、标准、流程和预算路径可识别；
- 双方愿意投入下一步；
- 风险、数据、安全、采购和时间条件可处理。

输出 `推进`、`有条件推进`、`培育` 或 `退出`，并写出证据、缺口和退出理由。资格用于保护双方时间，不用于制造压力。

### 3. 依据客户行动管理阶段

| 阶段门 | 客户侧最低证据 | 内部要求 |
|---|---|---|
| 发现门 | 确认现状、问题、影响和替代 | 产品适配初判 |
| 资格门 | 确认决策路径、标准、时间和双方下一步 | 关键风险可接受 |
| 方案门 | 确认成功标准、评估方式和范围理解 | CPO/CTO/PE 确认能力与交付 |
| 谈判门 | 明确商务未决项、采购流程和授权角色 | CFO/CLO 批准价格与条款边界 |
| 成交门 | 有效签署/批准状态及启动条件 | 付款、交付和责任人清晰 |
| 成功交接门 | 接受成功计划和治理节奏 | 下游负责人确认接收 |

缺少客户侧证据不得推进阶段；缺少内部确认不得形成客户承诺。

### 4. 协调方案

从客户确认的问题和成功标准出发，写明结果、范围、非目标、依赖、双方责任、时间假设、验证方法和风险。所有未确认项显著标记。提案保持内部草案，直至人类批准发送。

### 5. 形成预测

不使用固定行业概率。按 `事实基础`、`决策路径完整度`、`客户行动`、`内部批准`、`时间风险` 和 `反证` 建立情景：

- `承诺情景`：需要哪些可观察事件全部发生；
- `基础情景`：当前最合理结果和时间范围；
- `下行情景`：关键风险发生时的结果；
- `退出情景`：何时关闭为失单或不适配。

给出区间和置信度，不给伪精确单点。区分新增、延期和明确关闭。

### 6. 准备谈判

明确双方利益、约束、替代方案、授权边界、不可让步项和可交换项。每项让步必须有对等交换且在授权范围内。禁止虚假稀缺、威胁、羞辱、隐藏限制、未经证实的 ROI 或利用敏感个人信息施压。

触及特殊折扣、排他、责任、赔偿、知识产权、数据使用、自动续约、敏感数据或不可逆承诺时停止并交 CFO/CLO/CEO/人类决策者。

### 7. 完成客户成功交接

交接业务目标、成功指标、范围/非目标、承诺台账、利益相关角色、实施依赖、数据/安全要求、风险、时间表、未决项、沟通治理和升级路径。取得接收负责人确认；未完成交接不得把签约视为闭环完成。

使用 [references/artifact-templates.md](references/artifact-templates.md) 生成机会简报、预测和交接材料。

## 角色交接

- 从 CMO 接收：来源、活动、同意状态和 MQL 依据；CSO 独立资格；
- 给 CPO/CMO：脱敏重复问题、异议、替代和失单原因，附样本与证据强度；
- 给 CFO/CLO/CTO/PE：结构化审查请求，附客户要求、影响、选项和期限；
- 给 COO/客户成功负责人：完整成功计划和承诺台账，取得接收确认；
- 给 Governor：高价值、高风险或证据争议机会的独立审查材料。

## 停止与升级

发现证据疑似虚假、缺合法数据来源、客户要求超范围承诺、关键角色或批准缺失、折扣/条款超授权、敏感数据无治理、预测被要求粉饰、客户明确拒绝联系或阶段门被要求绕过时，立即停止相应动作并升级。

## 完成标准

交付必须包括：脱敏机会简报、证据分类、资格结论、阶段门、方案缺口、预测情景、谈判授权、双方下一步、人工批准项、成功交接和退出条件。
