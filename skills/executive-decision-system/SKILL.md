# 高管决策系统

把战略判断写成一份能执行、能反驳、能复查的决策记录。保持选项真实、机会成本显性、责任唯一；不要用框架替代判断。

## 输入

开始前收集；缺失项标为未知，不自行补成事实：

- 决策问题、目标受众和最晚决策点；
- 期望改变的公司级结果与时间范围；
- 已知事实、来源、关键假设和置信度；
- 资源上限、不可突破的约束与已承诺事项；
- 至少一个可行替代方案，以及维持现状的后果；
- 需要咨询的领域负责人和需要人类批准的事项。

## 决策流程

### 1. 固定问题

用一句话写出“为实现什么结果，必须在什么选项之间作何种选择”。同时列出非目标，防止把多个决定混成一个。

### 2. 建立事实底座

分别记录：

- **事实**：可定位来源、日期和适用范围；
- **假设**：尚未证实但影响选择的判断；
- **未知**：当前没有足够证据回答的问题；
- **约束**：现金、时间、人才、技术、法律、信任或可逆性边界。

找出一个最可能推翻当前偏好、且能够被验证的关键假设。

### 3. 构造可比选项

至少比较两个可行选项，并保留“维持现状”。对每个选项使用同一口径评估：

- 对目标结果的预期贡献；
- 所需资金、时间、人才和管理注意力；
- 机会成本与必须停止或延后的事项；
- 主要风险、可逆性和最坏可信后果；
- 领先证据、滞后结果和最短验证周期。

不要制造稻草人选项，也不要用未经校准的总分掩盖关键差异。

### 4. 通过决策门

仅当以下条件全部满足时给出决定：

- 问题、成功结果和非目标可判定；
- 关键事实有来源，关键假设已显式标注；
- 真实替代方案按同一标准比较；
- 资源来源、机会成本和停止项明确；
- 每个重大风险有领域负责人意见或待复核标记；
- 决定有唯一负责人、检查点和退出条件；
- 外部承诺、资金、法律、凭证、部署或不可逆动作已列为待人类批准。

任一项不满足时，输出“暂缓决定”或设计最小可逆验证，不伪造确定性。

### 5. 配置执行与复查

为决定指定：唯一负责人、资源边界、首个可验证里程碑、成功/失败信号、最晚升级点、复查日期和停止条件。只配置结果和边界，不越过 COO 设计详细运行流程。

## 停止与升级

- 关键事实相互矛盾、不可逆风险未评估或资源来源不明：停止作决定。
- 财务、法律、安全、技术或隐私判断超出能力：交对应负责人出具意见。
- 跨角色资源冲突无法在既定目标内解决：升级 CEO 或人类负责人。
- 涉及现实世界重大承诺：只提交建议与风险，不代替人类授权。

## 相邻角色边界

- CEO 使用本 Skill 选择方向和配置资源。
- COO 接收已确认决定，设计价值流、节奏与异常处理。
- 专业 C-suite 角色提供领域事实与方案，不由本 Skill替代。
- Governor 独立检查声明和证据，不由决策者自我批准。
