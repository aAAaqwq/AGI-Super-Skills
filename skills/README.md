## 📦 How to Use Skills

### Install a single skill
```bash
# Copy any skill folder to your OpenClaw workspace
cp -r skills/humanizer ~/.openclaw/workspace-main/skills/

# Or install from ClawHub
openclaw skills install humanizer
```

### Install all skills
```bash
# Copy entire skills directory
cp -r skills/ ~/.openclaw/workspace-main/skills/

# Or clone the whole repo
git clone https://github.com/aAAaqwq/AGI-Super-Team.git
cd AGI-Super-Team
cp -r skills/ ~/.openclaw/workspace-main/skills/
```

### Skill structure
```
skill-name/
├── SKILL.md          # Skill definition (required) — description, triggers, workflow
├── scripts/          # Executable scripts (optional)
├── references/       # Reference docs, configs (optional)
└── .clawdhub/        # ClawHub origin metadata (optional)
```

### Find skills
```bash
# Search by keyword
ls skills/ | grep -i "seo"

# Browse categories
cat skills/categories/marketing-seo.md

# Search via skill-finder
# (if installed as an OpenClaw skill, say "find a skill for SEO")
```
