## 二、策略含义（模拟盘跑的是什么）

### 核心逻辑：布林带均值回归

```
布林带收窄 = 横盘 → 在下轨买、上轨卖；在上轨卖、下轨买。
不赌方向，只吃区间振荡的统计优势。
```

### 一次交易的完整旅程

1. **入场触发**：15m K线 `%B < 0.15`（贴下轨，做多）或 `%B > 0.85`（贴上轨，做空）
2. **入场价**：轨道 + 0.1%（`entry_threshold/2`，贴轨道挂单）
3. **止盈 TP**：**对侧轨道**（轨对轨，吃整个 2σ 空间）
4. **止损 SL**：入场轨外 0.15%（`stop_buffer`）
5. **触发方式**：
   - 逐笔成交（`@trade` 流）秒级判断 TP/SL
   - 每根 15m K线结束，用 K线 high/low 判断穿透
   - 30 秒兜底轮询，弥补 trade 流稀疏
6. **超时平仓**：持仓超过 12 根 K 线（3 小时）强制平仓

### 三重过滤器（入场前必须全过）

| 过滤器 | 规则 | 目的 |
|--------|------|------|
| 🔴 趋势过滤 | 1h 中轨斜率：做多需 `> -0.06%`，做空需 `< +0.06%` | 确认横盘，防接飞刀 |
| 🟡 RSI 确认 | 做多需 RSI ≤ 55，做空需 RSI ≥ 45 | 不在极端位追单 |
| 🟢 BB 甜区 | 宽度 `0.8% ≤ w ≤ 2.5%` | 太窄不够覆盖成本，太宽不是真横盘 |

### 关键参数（config.yaml）

| 参数 | 值 | 含义 |
|------|-----|------|
| BB 周期 / 标准差 | 20 / 2.0 | 2σ 布林带 |
| 杠杆 | 10x | 固定 |
| 单笔名义 | $100（max_position_usd）| 固定仓位，非 all-in |
| 单笔风险 | 账户 2% | 紧止损 + 小仓位的组合 |
| 冷却 | SL 后 3 根 K 线 | 防连续止损 |
| 手续费 | 双边 0.08% | 已计入盈亏 |

## 三、如何查看模拟盘

```bash
# 实时日志（开平仓/心跳）
tail -f paper.log

# 进程状态
ps -p $(cat paper.pid)

# 落盘的模拟交易（有交易后）
cat paper_trades.json

# 停止（退出时打印汇总）
kill $(cat paper.pid)
```
