## 数学检验（75x）
- 到TP +1% = +75% 本金；到 -1% 止损 = -75% 本金（对称）
- R2: p=0.714 → EV = 0.714×0.75 − 0.286×0.75 = **+0.32（每单 +32% 本金）**
- 盈亏平衡 p = 50%；R2 显著高于此
- ⚠️ 连亏风险：P(3连亏) = 0.286³ ≈ 2.3%，75x 下 3 连亏即 -225% → 必须小仓位（单笔 ≤10-20% 本金）

## ⚠️ 关键限制（别忘）
1. 池子选的是"当前正在暴动"的币 → 吃的是**趋势延续行情红利**；震荡/趋势反转时到TP率会大幅下降
2. 到TP按"K线内触及+1%"计——小币插针/滑点可能不按理想价成交
3. 仅 10 天窗口；需前向 paper 验证（记录真实触发→结果）
4. 手续费/资金费未计入
5. 超时单（约 10-34%）按没吃到 TP 计，实际是微亏/平推

## 建议执行口径（若前向验证通过）
1. 只用 **R2 或 R6**（放量强体 / 高动量放量）
2. 只做 **15m/1h 趋势仍同向**的币（避免趋势末端进场）
3. 单笔风险 ≤ 总本金 10-20%，别满仓 75x
4. 先 paper 跑 2 周（每天记录触发与结果），真实到TP率仍 ≥65% 再考虑小仓实盘
