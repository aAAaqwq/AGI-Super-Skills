# ⚡ coin-vp-scanner · R2 高确定信号扫描器 v3

扫描币安 USDT 永续，**只报"刚触发 R2 高确定信号"的币**——基于 10 天历史回测
（`backtest-findings.md`），这类信号 **15 分钟吃到 +1% 的概率 ≈ 71%**。

## R2 信号定义（回测校准）
```
最近一根收盘 5m K线:  |实体| ≥ 0.5%   (强势单根)
且该 K线量能 ≥ 2x 基线   (放量确认, 非散户小单)
方向 = 该根 K线 方向
加严: 信号方向与 15m 短趋势同向 (TREND_FILTER, 默认开 → 更抗震荡)
→ 参考到TP率 ≈ 71% (纯R2) / ≈69% (加趋势过滤)
```

## 使用
```bash
python3 scanner.py                # 只报刚触发 R2 的信号 (默认加 15m 趋势过滤)
python3 scanner.py --no-trend     # 纯 R2 (71%), 不过滤趋势
python3 scanner.py --telegram     # 扫到信号顺带推 Telegram
```
**空结果 = 现在没有币刚触发 R2**（R2 只在"爆发那一刻收盘"出现）。建议挂定时每 5 分钟跑。

## 字段
| 字段 | 含义 |
|------|------|
| 实体% | 触发那根 5m 的涨跌幅（≥0.5% 才算）|
| 放量x | 该 K线量能 / 7.5h 基线（≥2x 才算）|
| 15m% / 1h% | 短趋势 / 大方向动量 |
| 参考到TP率 | 回测: 15min 内先到 +1% 的历史概率 |
| ⚠️ | 24h 已动超 ±45%（可能追高）|

## ⚠️ 铁律（务必读）
1. **71% = 回测值，不是保证**。它吃的是趋势行情红利——震荡/反转期会掉。
2. 单笔只押**总本金 10-20%**；到 -1% **无条件止损**（75x 下 -1% ≈ -75% 本金）。
3. **先 paper 验证 2 周**（到TP率仍 ≥65% 再上真钱）。脚本见 roadmap。
4. 这是信息工具，非投资建议；任何高倍数收益图都有幸存者偏差。
