## 6. 实盘 66.1% 的可能来源 (分析)

### 假说 1: 小样本统计波动 (概率: 高)
- 298 轮, p=0.50, 观测到 66.1% 的概率 ≈ 
- `P(X≥197|n=298,p=0.5) = ?`
- 二项分布, σ = √(298×0.5×0.5) ≈ 8.63
- z = (197 - 149) / 8.63 ≈ 5.56
- **P < 0.00001** → 统计显著，不太可能是纯运气

### 假说 2: 近因偏差/市场regime (概率: 高)
- 实盘数据集中在 5月23-27日 (仅5天密集数据)
- 可能碰巧处于趋势性 regime, momentum 因子短期有效
- 但 5月5-6日 也达到 63%, 说明不是单一事件

### 假说 3: 前视偏差 (概率: 中)
- 实盘引擎在 K线 progress=0.9+ 时运行
- 此时 current close ≈ final close
- momentum/RSI/meanrev 因子间接包含了 "未来" 信息
- 这解释了前视回测 61.1% vs 保守回测 47.4% 的差距
- 实盘 66.1% ≈ 前视 61.1% + 小样本波动

### 假说 4: Orderbook alpha (概率: 低)
- 回测中 imbalance/microprice = 0
- 实盘日志中这两个因子也为 0.000
- **实盘也未使用 orderbook 数据!**
- 排除此假说

## 7. 顶尖交易员视角 — 根因诊断

### 问题链:
```
11因子体系中:
  momentum (权重最大) → 方向一致性48.1% (反向!)
  rsi                    → 方向一致性47.3% (反向!)
  meanrev                → 方向一致性51.7% (仅正信号)
  volume/v_reversal/...  → 回测中恒为0 (无贡献)
  imbalance/microprice   → 实盘也为0 (从未工作)
```

### 核心诊断:
1. **因子选择错误**: BTC 5分钟级别, 价格动量/RSI 均无延续性, 甚至均值回归效应也极弱
2. **权重未校准**: BASE_W 全部基于直觉设定, 从未在历史数据上优化
3. **Bull惩罚 0.92 无依据**: 在整体 bearish 市场中系统性偏空, 进一步降低准确率
4. **置信度校准失效**: Platt Scaling 在无 signal 的因子上无意义
5. **引擎设计逻辑错**: 用历史价格统计量预测5分钟价格方向 → 市场微观结构不是这样工作的

### 实盘 "幻觉":
- 实盘引擎在 progress=0.9+ 时运行, 本质上不是 "预测5分钟后"
- 而是确认当前K线已有走势 → 属于 "后视" 而非 "前瞻"
- Polymarket 下注窗口与引擎 tick 时间可能存在对齐偏差
