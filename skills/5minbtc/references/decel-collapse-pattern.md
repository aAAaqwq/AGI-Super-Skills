# decel 极值崩塌模式 — 完成V反检测

> 日期: 2026-06-17
> 触发轮: 23:10 candle
> 上下文: bear→bull 快速趋势逆转

## 模式定义

**decel 极值崩塌**: decel因子从 +1.0（饱和）在单一K线内崩塌至接近0，意味着"减速"已完成，加速反弹正在发生。

```
decel timeline (22:50→23:10):
22:50: decel=+1.0  mom=-0.95  → 下跌减速中（V反初期，捕捉到"减速"=即将止跌）
22:55: decel=+1.0  mom=-0.81  → 减速持续（仍在减速）
23:00: decel=+1.0  mom=+0.18  → 减速持续但mom已翻正
23:10: decel=+0.01 mom=-0.88  → 💥 崩塌！减速瞬间完成→反弹加速中
```

## 信号序列

```
Phase 1: decel 攀升至+1.0 + mom 深度负值 → "正在刹车"（R1 适用: decel优先于mom）
Phase 2: decel 维持+1.0 + mom 修复          → "刹车踩住了"（等待反转）
Phase 3: decel 崩塌+0.0  + MACD hist 急速修复 → "松开刹车，踩油门"（反转已发生）⚠️ 本规则
```

## 与 R1 规则的区别

| 规则 | 场景 | 信号 | 操作 |
|------|------|------|------|
| R1 (mom/decel冲突) | 即将反转 | mom↓ decel↑ 方向冲突 | decel优先 → 预测反转方向 |
| decel崩塌 (新) | 已发生反转 | decel从+1.0→0 MACD急速修复 | LLM覆盖引擎 → bull |

R1 捕"即将"，本规则捕"已经"——两者互补。

## 触发条件

必须同时满足:
1. decel 在最近2根K线内从≥0.9 → ≤0.05 (崩塌幅度≥85%)
2. MACD hist 在同期急速修复 (从≤-20 → ≥-10 或翻正)
3. RSI 在同期有明显抬升 (≥5点)

满足时: LLM应覆盖引擎方向，向 decel崩塌前的动量相反方向预测。

## 错误例: 23:10 candle

- Engine: bear/weak/conf 45 (EMA死叉、MACD hist -5.7仍在负、momentum -0.875)
- LLM: 未覆盖，信任引擎 → **方向❌**
- Actual: +0.37% strong bull rally ($65,234 from $64,991.99)
- 根因: engine 在消化15根K线的bear momentum，滞后于已发生的反转
- 正确做法: 检测到 decel +1.0→+0.011 崩塌 + MACD hist -32→-5.7 急速修复 → LLM应覆盖为 bull
