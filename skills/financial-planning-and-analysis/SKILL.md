# 财务规划与分析

把战略转成可复算的资源选择，并让现金时点、完整成本、下行情景和控制先于乐观叙事。本 Skill 提供管理分析，不构成会计、审计、税务或投资专业意见。

## 收集最小输入

确认决策问题、业务模式、期间、币种、现金/权责发生、税前/税后、名义/实际口径、历史实际、当前预算、合同条件、运营驱动、负责人、风险偏好、资金约束、里程碑和决策期限。

给每个数字标记：`ACTUAL-RECONCILED`、`ACTUAL-UNRECONCILED`、`ESTIMATE`、`ASSUMPTION`、`TARGET` 或 `UNKNOWN`。不得把余额、报价、汇率、税率或市场数据当成当前事实，除非有来源和日期。

## 工作流

### 1. 建立模型契约

在计算前写明：决策、版本、负责人、币种、期间、口径、数据截止日、输入来源、未包括项、复核日期和失效条件。分离输入、公式、假设与输出；不得硬编码结论。

### 2. 建立驱动模型

从可观察的经营驱动出发：客户/订单/席位、价格、转化、留存、使用量、交付能力、人员、供应商、基础设施和支付条件。说明收入确认与现金收取的时间差。

在数据允许时连接：

- 损益：收入、成本、毛利、费用和经营结果；
- 资产负债：现金、应收/应付、递延项目和融资；
- 现金流：经营、投资、融资活动及期末现金。

若无法可靠连接三表，明确局限并只交付适用的管理现金模型。

### 3. 计算完整单位经济

定义“单位”和贡献层级，纳入获客、交付、服务、退款、坏账、支付费、基础设施和时间成本。CAC、LTV、毛利、贡献利润和回收期必须说明公式、观察窗口、队列差异与假设；不得用平均值掩盖严重分布差异。

### 4. 建立滚动预测

使用适合现金风险的粒度与周期。至少建立：

- 基准：当前最佳估计；
- 上行：明确哪些驱动改善；
- 下行：收入延迟、需求较弱或成本超支；
- 压力：融资失败、重大客户流失或供应中断等可承受边界。

对每个情景写触发器、概率仅在有依据时使用、现金最低点、跑道和管理动作。

### 5. 做敏感性与临界点分析

识别最能改变结论的 2–5 个驱动因素。展示单变量/双变量敏感性、盈亏平衡点、现金耗尽点或停止阈值。避免用复杂模型掩盖输入不确定性。

### 6. 解释实际—预算差异

将差异分解为价格、数量、组合、时点、效率和一次性因素。区分可控与不可控、暂时与结构性；写明数据对账状态、责任人和纠偏动作，不为美化表现改基线。

### 7. 比较资本配置方案

逐项比较投入、资金来源、现金时点、机会成本、预期价值逻辑、最坏损失、可逆性、管理注意力、里程碑和退出条件。只有现金流结构适用时才使用 NPV/IRR，并同时说明折现率、终值和再投资等限制。

优先保护流动性与必要义务；可逆决策用小额分阶段实验换信息；沉没成本不构成继续投入理由。

### 8. 设计财务控制

明确谁提出、复核、批准、执行和对账。设置预算上限、双人复核、例外记录、供应商/收款人变更验证和异常升级。分析者不得索取或使用银行凭据、私钥、支付卡、完整账号或验证码。

## 决策门

1. **数据门**：来源、日期、口径、完整性和对账状态可见；
2. **经济门**：收入驱动、完整成本、现金时点和机会成本明确；
3. **下行门**：下行/压力情景、最低现金和可承受损失可见；
4. **控制门**：预算上限、权限分离、负责人、里程碑和停止条件齐全；
5. **专业门**：会计、税务、审计、证券和投资问题已标记专业复核。

未通过时写 `BLOCKED`、缺失数据、责任人和解除条件，不用伪精确数字补空白。

## 交付模板

```markdown
# 财务规划与资本决策包
## 决策、模型口径、版本与数据截止日
## 数据来源、对账状态与关键假设
## 驱动模型与三表/现金连接
## 单位经济与队列差异
## 基准、上行、下行和压力情景
## 敏感性、临界点、跑道与流动性
## 实际—预算差异及原因
## 资本配置选项、机会成本和建议
## 预算上限、里程碑、停止条件和控制
## 风险、未知、专业复核和批准状态
```

## 停止、批准与交接

现金耗尽或持续经营风险、重大预算偏差、无法对账、控制被绕过、疑似欺诈、税务/证券/融资/审计事项，或任何付款、转账、投资、借贷、开户、报税和账户访问请求，立即停止并升级。

资金动作始终由授权人类按既定控制执行；本 Skill 不保证收益、融资、估值、节税或预测准确性。数据口径交 CDO，运营驱动交 COO，产品/技术投入交 CPO/CTO，合同/税务/证券边界交 CLO，重大计算交独立复核者或 Governor。
