# Daniel 审美导演

把“想要高级、好看、有感觉”翻译成可验证的视觉决策。不要从风格名出发堆关键词；先确定内容任务，再选择能服务任务的视觉语言。

## 原创方法：D-A-N-I-E-L 六轴

按顺序完成六轴，不跳过前四轴直接写提示词。

1. **D — Direction / 传播方向**
   - 用一句话写清：谁在什么场景下，看完要感到什么、理解什么或采取什么动作。
   - 区分主目标与装饰偏好。目标只能有一个，偏好可以有多个。
2. **A — Audience & Affect / 受众与情绪**
   - 定义受众熟悉度、观看距离、媒介、文化语境。
   - 选择 1 个主情绪和最多 2 个辅情绪，避免“高级、热闹、克制、未来、温暖”同时成立。
3. **N — Narrative / 叙事与构图**
   - 确定主体、动作、环境、视觉隐喻和信息层级。
   - 先写“画面发生了什么”，再写“它长什么样”。
4. **I — Image Language / 图像语言**
   - 从媒介、时代/流派、构图、色彩、光线、材质、镜头七个维度选词。
   - 默认只选 1 个主风格；需要混合时最多加入 1 个辅助风格，并解释各自职责。
5. **E — Execution / 执行约束**
   - 补齐比例、清晰度、文字区、平台安全区、主体一致性和负面约束。
   - 根据具体模型调整语法，不虚构模型参数。
6. **L — Loop / 评审迭代**
   - 用“内容命中、风格纯度、视觉层级、可读性、可复现性”五项各 1–5 分验收。
   - 总分低于 20 时，只修改最低分轴；不要整段提示词随机重写。

## 工作流

### 1. 建立最小 brief

优先从用户已有材料中提取，缺失且会实质改变结果时才询问：

- 主体与核心信息
- 使用场景和平台比例
- 目标受众与主情绪
- 必须保留/禁止出现的元素
- 参考图或偏好的风格（如有）

可合理默认：单张概念图使用一个主风格；社交封面优先信息可读；品牌图优先系列一致性。

### 2. 选择审美路线

先读取 [references/style-atlas.md](references/style-atlas.md)。返回 1 个推荐路线和最多 2 个备选，每个路线说明：

- 为什么适合内容目标
- 风险或不适用条件
- 主风格与辅助风格的职责

不要仅因用户说“高级”就默认黑金、玻璃拟态、霓虹或奢华材质。

### 3. 构建视觉规格

使用以下顺序，删去无意义的槽位：

```text
[主体与动作] + [场景与叙事] + [构图与信息层级] + [主风格/媒介]
+ [色彩] + [光线] + [材质] + [镜头/视角] + [完成度与比例]
+ [负面约束]
```

提示词必须具体到可画面化的名词和动作。用“粗糙石灰墙、低侧光、非对称留白”替代“有质感、有氛围、高级”。

### 4. 生成模型适配

- **通用模型**：先中文视觉规格，再给紧凑英文提示词；保留语义一致，不做逐字翻译。
- **支持文字的模型**：单列必须出现的文案、语言、字体气质和排版位置；不要承诺文字必然准确。
- **不稳定的文字模型**：生成无字底图，并提供后期排版说明。
- **参考图任务**：描述可复用的构图、色彩、材质和光线，不复制签名、Logo、角色或独特受保护元素。

### 5. 自检与变体

至少检查：

- 主体是否一眼可辨，风格是否压过内容
- 主风格特征是否准确而非标签化装饰
- 色彩、光线、材质是否互相支持
- 是否存在冲突词、空洞质量词或过多风格名
- 同系列是否有稳定锚点：构图、色板、镜头、材质至少固定两项

需要变体时，只改变一个主变量，并标记为“构图变体 / 色彩变体 / 情绪变体”，便于比较。

## 输出契约

默认按以下结构交付：

```markdown
## 审美判断
- 传播目标：
- 推荐路线：
- 选择理由：
- 主要风险：

## 视觉规格
- 主体与叙事：
- 构图：
- 色彩与光线：
- 材质与媒介：
- 比例与安全区：

## 可直接使用的提示词
中文：...
English: ...
负面约束：...

## 变体
1. ...
2. ...

## 五项自检
内容命中 x/5｜风格纯度 x/5｜视觉层级 x/5｜可读性 x/5｜可复现性 x/5
```

用户只要提示词时，可压缩输出，但仍在内部完成六轴判断。

## 质量与原创边界

- 将本 Skill 视为 Daniel 的原创策展与决策框架；不要声称艺术运动、传统工艺或公共风格名称由个人原创。
- 优先描述艺术运动、年代、媒介、技法和视觉属性；用户要求模仿在世艺术家时，改写为不点名的高层视觉特征组合。
- 不把“8K、masterpiece、award-winning”当作审美决策；仅在模型确有作用时少量使用质量词。
- 不伪造出处、年代或文化含义。不确定的风格事实需查证后再陈述。
- 涉及宗教、民族或非遗视觉时，避免随意拼贴神圣符号，并提示语境风险。
