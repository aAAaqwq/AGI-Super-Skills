# Daniel voice examples

## Core shape

Use this order when the source supports it:

1. **Impulse** — what Daniel wanted to do before the evidence was complete.
2. **Agent resistance** — one short action or sentence that interrupts the impulse.
3. **Evidence** — no more than three decisive observations.
4. **Rule** — when to act and what would invalidate the idea.
5. **Outcome** — one confirming event, clearly marked as later evidence.
6. **Meaning** — the Agent did not predict; it forced clearer thinking.

Not every post needs all six parts. Under a hard limit, keep impulse, evidence, rule, and meaning.

## Canonical trading example

```text
BANKUSDT下杀前，我想抢跑做空。Agent按住我：“BB收紧，只说明风要来。”

它只认3件事：低点下移、买量14.3M→6.1M、0.05619反复受压。跌破0.05400才执行；放量站上0.0565就认错。

后来151M量柱砸出0.05208。

它没预测，只是逼我写清：为什么做、何时做、错了怎么办。

复盘，不是喊单。
```

## Generic-to-Daniel transformations

Generic:

```text
AI能够帮助交易者克服情绪并提高决策质量。
```

Daniel:

```text
我想抢跑，Agent先问我：“错了怎么办？”

那一刻它没有给答案，只是把我的情绪变成了一条必须写清的规则。
```

Generic:

```text
六层证据完美对齐，模型成功预测了下跌。
```

Daniel:

```text
结构、量价和触发条件同时偏空。后来的下跌只算验证，不算预言。
```

## Compression priorities

Cut in this order:

1. Repeated disclaimers and conclusions.
2. Indicator definitions the target audience already knows.
3. Secondary numbers and timestamps.
4. Section labels and list formatting.
5. Decorative adjectives and generic claims.

Protect in this order:

1. The real human tension.
2. The decisive evidence.
3. The trigger and invalidation condition.
4. The final insight.

## Reject these patterns

- “震撼”“暴富”“精准抄底”“完美逃顶” and other performance theater.
- Cute Agent dialogue, repeated quotation marks, or cinematic scene-setting.
- More than three indicator families in a short post.
- A disclaimer longer than the actual insight.
- Claims that the Agent predicted, guaranteed, or autonomously executed a trade.
- A thread produced only because the writer failed to compress.
