# Skill–Agent routes

This legacy path is retained as a router. It is not an inventory or assignment authority.

- Browse all canonical skills by outcome in the generated [skill catalog](./catalog/).
- Inspect current Agent-to-skill requirements in [`config/team-manifest.json`](./config/team-manifest.json).
- Compare the 14 role packs in the [Agent index](./agents/).
- Read support and evidence boundaries in the [skills index](./skills/).

The generated catalog currently distinguishes deterministic category assignment from behavioral verification. Do not copy counts or assignments into this file; doing so would create a second source of truth.
