# 📚 Cookbooks

Cookbooks are long-form references, not installable Skill entrypoints. Use them when a focused `SKILL.md` is too small for the subject.

| Collection | Scope |
|---|---|
| [Crypto learning](./crypto-learning/) | Market concepts and research material |
| [Repository distillation](./distill-repos/) | Turning source repositories into reviewable knowledge |
| `celebrity-mindset/` | Creative persona reference material |
| `knowledge-book/` | Knowledge-system notes |
| `prompt-engineering-learning/` | Prompt engineering curriculum |
| `quant-learning/` | Quantitative research curriculum |
| `self-media-operations-handbook/` | Content operations handbook |

Cookbook presence does not establish factual freshness, safety, or harness compatibility. Inspect sources and dates before applying advice.
