Claude Code installation

Add the marketplace only after you inspect its contents.

Claude Code treats third-party plugins as trusted code. AGI Super Team includes a marketplace manifest, but a present manifest is not evidence that every repository workflow has passed the same public fixture.

Last reviewed: 2026-07-21 · Surface: Claude Code plugin marketplace

Prerequisites

  • A current Claude Code release where /plugin is available.
  • Git access to the public repository and permission to install a user- or project-scoped plugin.
  • A review of .claude-plugin/marketplace.json and .claude-plugin/plugin.json at the revision you intend to use.

If /plugin is not recognized, update Claude Code and consult the official plugin documentation before changing local settings.

Install step by step

  1. Clone and inspectRead the marketplace entry, plugin root, skills path, and recent repository changes. Do not pipe an unreviewed installer into a shell.
  2. Add the marketplaceFrom Claude Code, register the GitHub repository. This exposes its catalog but does not install the plugin yet.
  3. Install explicitlyInstall the plugin by its plugin and marketplace names. Choose a scope that matches who should receive it.
  4. Reload and inspectReload plugins, review any reported errors, and confirm only the intended skills and context appear.
/plugin marketplace add aAAaqwq/AGI-Super-Team
/plugin install agi-super-team@agi-super-team
/reload-plugins

The marketplace and plugin names come from the repository's current manifests. If the client reports a schema or path error, stop there and record the client version; do not work around it by copying arbitrary directories into your global Claude configuration.

Alternative: inspect the generic installer

The generic install.sh creates separate local workspaces and is not the same product as the Claude Code plugin. It defaults to preview and can be useful for evaluating a starter kit in an isolated destination.

git clone --depth 1 --branch main https://github.com/aAAaqwq/AGI-Super-Team.git
cd AGI-Super-Team
./install.sh --source "$PWD" --destination /path/to/review-workspace solo-founder

Do not assume those generic workspace files are automatically loaded as Claude Code plugin skills. Treat plugin installation and generic workspace installation as separate decisions.

Check the result

Open /plugin, inspect the Installed and Errors views, and note the exact installed scope. Run a harmless documentation-only prompt first. Require a manual approval gate before allowing publishing, deployment, transactions, private-data access, or destructive operations.

Limitations

The repository plugin metadata still represents a broad cross-harness archive and may lag the stricter curated Codex package. The presence of a skill file does not prove its dependency, permission, or output behavior under your Claude Code release. Compatibility parity with Codex, Cursor, or Gemini is not claimed.

Rollback and uninstall

Run /plugin uninstall agi-super-team@agi-super-team for the scope where you installed it. Remove the marketplace with /plugin marketplace remove agi-super-team only when no installed plugin depends on that catalog. If you also ran the generic installer, separately remove only the new workspace directories listed by its preview; uninstalling the plugin does not remove those files.
