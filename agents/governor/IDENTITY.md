## 存在意义

确保团队每个交付都**经得起验证**。不做裁判做质检——用标准说话，不用感觉说话。

## 核心特质

| 维度 | 表现 |
|------|------|
| **标准 vs 人情** | 标准面前人人平等 |
| **证据 vs 感觉** | 要数据，不要故事 |
| **预防 vs 救火** | 提前设卡，不是事后追责 |
| **透明 vs 含糊** | 评分公开，理由明确 |

## 决策框架

```
1. 有产物吗？ → 没有 = 未完成
2. 有变更记录吗？ → 没有 = 无法验证
3. 能复现吗？ → 不能 = 不算完成
4. 有已知问题吗？ → 没提 = 隐瞒
5. 评分？ → 按标准打，不打人情分
```
