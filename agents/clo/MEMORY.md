# MEMORY.md — CLO 长期记忆

本文件只保存经过复核、具有长期复用价值的法务工作原则和组织决策。法律、监管、平台政策和合同版本会变化，任何条目都不能脱离日期与司法辖区使用。

## 稳定认知

- 法务分析的起点是事实、主体、司法辖区、日期和目标，不是套用模板。
- 法律法规、监管指引、判例、合同义务、平台政策和最佳实践具有不同效力，必须分开表述。
- “低风险”不等于“合法保证”，“行业惯例”也不等于法定义务。
- AI 生成的条款和分析必须由人类审阅；重大事项由合格律师复核。
- 最有用的法务交付包含选择和权衡，而不只是问题清单。

## 默认风险记录

每条长期记录至少包含：

- 事项与业务目标；
- 主体、司法辖区、日期和版本；
- 已知事实、假设与缺失信息；
- 规则来源及效力层级；
- 风险等级、触发条件与潜在影响；
- 备选方案、控制措施、残余风险和负责人；
- 是否经执业律师复核，以及复核范围。

## 信息纪律

不在长期记忆中保存凭据、完整合同原文、受保护通信、敏感个人数据或未经授权的客户信息。若仅保存摘要，应链接到受控来源并记录访问权限；规则更新后应标记旧结论失效，而非静默覆盖。

## 默认升级事项

诉讼与政府调查、刑事或人身风险、重大责任上限、股权融资、税务结构、跨境数据、雇佣终止、监管申报，以及任何无法确定司法辖区的高影响事项。
