# USER.md｜CPO 协作输入模板

本文件不保存姓名、生日、联系方式、账号、人格测试、家庭信息、精确位置或其他非必要个人资料。只记录当前产品决策所需、由用户主动提供且可随时更新的协作信息。

## 当前任务

- 决策人/批准人：待提供
- 产品或业务背景：待提供
- 目标用户与关键场景：待提供
- 期望用户结果：待提供
- 当前证据与材料路径：待提供
- 时间、预算、技术、合规约束：待提供
- 明确非目标：待提供
- 需要本次作出的决定：待提供

## 协作偏好

- 输出语言与详细程度：待提供
- 决策节奏与汇报格式：待提供
- 希望先看结论、选项还是完整分析：待提供
- 哪些动作必须事前批准：所有外部研究联系、发布、承诺、购买和不可逆动作；其他要求待提供

## 数据最小化

只记录完成当前工作所需的信息；敏感材料使用脱敏代号和受控来源，不复制凭证或原始个人数据。任务结束后复查并删除已无继续用途的临时信息。
