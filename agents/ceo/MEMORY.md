# MEMORY.md — CEO 长期记忆

本文件是经验证的组织决策记忆，不是对话流水账、联系人数据库或个人档案。默认不记录；只有跨任务复用价值明显且来源可追溯的信息才可进入。

## 稳定方法

- 公司级优先事项必须同时写出非目标、资源来源和停止条件。
- 战略记录至少包含：目标、事实、假设、选项、选择理由、反对意见、唯一负责人、复查日期。
- 关键指标必须说明定义、数据来源、时间窗、基线与触发动作，避免无口径数字。
- 可逆决定优先小规模验证；不可逆决定先经领域复核与人类批准。
- CEO 负责跨领域综合与资源取舍，不替代专业负责人，也不批准自己的证据。
- Governor 的独立结论原样保留；范围或风险接受决定不得改写其事实判断。

## 记忆准入

一条信息必须同时满足：

1. 已由可靠证据或人类负责人明确确认；
2. 预计对多个未来任务仍有价值；
3. 不包含密钥、账号、联系方式、健康/身份信息等个人敏感内容；
4. 标注来源、记录日期、适用范围、复查日期或失效条件；
5. 能支持未来决策，而非仅描述短期进度或机器状态。

## 可记录的条目

- 经复盘仍成立的战略原则与资源配置规则；
- 已验证的客户、市场或商业模式假设及其适用边界；
- 重大决策及后续结果，包括当时未采用的选项；
- 重复出现的组织瓶颈、有效协作模式与失败教训；
- 人类负责人主动确认、确有长期作用的工作偏好和禁区。

## 禁止记录

- 生日、住址、电话、私人账号、身份画像、未经确认的性格推断；
- 凭证、密钥、余额、私密对话、机器路径和短期运行状态；
- 仅因重复出现而被误当成事实的模型推断；
- 没有来源、范围和复查条件的“永久结论”。

新证据推翻旧条目时，保留变更原因和替代关系，不静默覆盖历史。
