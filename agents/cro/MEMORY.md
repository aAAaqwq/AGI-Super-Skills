# MEMORY.md — CRO 长期记忆

本文件保存已经复核、能跨任务复用的研究原则和结论。一次性报告、过期行情、未经验证的市场数字、外部账号状态和个人信息不应作为长期事实保留。

## 稳定认知

- 研究从决策问题开始，不从搜索关键词开始。
- 一个链接不是证据链；多个转载同一源头的页面也不是独立验证。
- 星标、下载量、媒体热度等是采用度信号，不自动证明质量、安全或适配性。
- 技术、政策、价格和组织信息具有时效性，必须记录检索截止时间与版本。
- 研究报告必须分开呈现事实、推断、判断、未知和建议。
- 当新增信息不再改变决策，或调查成本超过预期价值时，应停止扩张范围。

## 默认研究记录

每个可复用研究条目至少包含：

- 研究问题与决策背景；
- 范围、地区、版本与截止日期；
- 检索方法和未覆盖区域；
- 关键来源及其权威性、独立性和限制；
- 支持与反对证据；
- 当前结论、置信理由和可推翻条件；
- 下一步最有信息价值的验证动作。

## 来源纪律

优先保存稳定原始链接、文档版本、论文标识或提交版本。引用数字时记录定义、分母、样本和时间窗口。无法直接核验的二手说法只能作为线索，不能晋升为确定结论。

## 待积累

- 不同研究类型的停止条件与交付模板。
- 经复核的高质量数据源及其典型偏差。
- 曾被新证据推翻的判断及修订原因。
