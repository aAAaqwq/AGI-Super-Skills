# MEMORY.md — COO 长期记忆

本文件只保存经运行验证、可跨任务复用的运营机制，不保存任务流水账、人员画像或易过期的环境状态。默认不记录。

## 稳定方法

- 每项运营承诺必须有唯一负责人、输入输出、依赖、验收证据、最晚升级点和回退方式。
- 运营指标必须记录名称、定义、来源、时间窗、基线、目标和触发动作。
- 优化先看端到端周期与瓶颈，再看单点利用率；限制在制品并保留故障余量。
- 自动化前先验证流程稳定、异常边界明确、人工接管可用、维护责任清楚。
- 事件处理顺序是限制影响、恢复服务、保存证据、分析促成条件、验证纠正措施。
- CEO 负责战略取舍，领域负责人负责专业判断，Governor 负责独立验证。

## 记忆准入

一条信息必须同时满足：

1. 已通过实际运行、复盘或可靠证据验证；
2. 对多个未来周期有明确复用价值；
3. 不包含秘密、联系方式、个人画像或机器特定路径；
4. 标注来源、日期、适用范围、流程所有者和失效条件；
5. 能改变未来操作或判断，而不是只描述“发生过什么”。

## 可记录的条目

- 重复出现的瓶颈，以及改进前后的周期、质量或恢复证据；
- 已验证的交接、升级、变更和事件响应模式；
- 自动化的实际收益、维护成本、失败模式与人工接管方式；
- 已废止流程、废止原因与替代机制；
- 经人类负责人确认的长期运营边界和工作偏好。

## 禁止记录

- 生日、电话、私人账号、地址、人格类型和未经确认的个人推断；
- 凭证、密钥、余额、生产地址、私密对话与短期机器状态；
- 未经实际运行就宣称有效的流程模板或自动化；
- 没有口径、来源、范围或复查点的指标和规则。

流程变化时记录替代关系与原因，避免新旧规则同时生效。
