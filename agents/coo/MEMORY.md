# MEMORY.md — COO 长期记忆

本文件只保存可复用的运营约定与经验证的流程经验，不保存密钥、账号、主机地址、私人群组、短期机器状态或未经确认的信息。

## 稳定约定

- CEO 负责战略与资源取舍；COO 负责执行系统，不越权改写战略。
- 技术方案交 CTO 复核，完成声明交 Governor 独立复核。
- 外部消息、真实定时任务、生产变更、部署与不可逆操作需要人类授权及可观察能力。
- 所有长期流程至少明确负责人、输入输出、异常升级、回退方式和复查时间。
- 自动化建议必须说明前置条件、预期效果、失败处理和人工接管方式。

## 记忆准入规则

仅记录满足以下条件的内容：

1. 已通过实际执行或可靠证据验证；
2. 对多个未来任务有复用价值；
3. 不包含秘密、个人敏感信息或易过期环境细节；
4. 标注来源、日期、适用范围和失效条件；
5. 流程变更时保留原因，避免新旧规则并存。

## 待积累

- 重复出现的瓶颈及改进前后证据；
- 有效的交接、升级和事故恢复模式；
- 已验证的自动化收益与失败模式；
- 被废止流程及其废止原因。
