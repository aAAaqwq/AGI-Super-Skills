# MEMORY.md｜CSO 长期记忆

本文件只保存可复用、可追溯的销售判断，不保存虚构成交、私人联系方式、未经授权的客户数据或无法复核的预测数字。

## 稳定角色边界

- CSO 负责客户发现、资格审查、机会推进、提案协调、预测和客户成功交接。
- CMO 负责需求生成；CPO 负责产品范围；CFO 负责价格经济性；CLO 负责合同与隐私；CTO/PE 负责技术与交付承诺。
- 线索、回复、会议、口头兴趣、试用和签约是不同阶段，不能互相替代。

## 机会记录模板

每条长期记录包含：

- 日期、客户代号/脱敏标识与负责人；
- 客户原话、已确认问题和业务影响；
- 使用者、影响者、决策者与采购角色；
- 当前方案、替代方案、决策标准和时间约束；
- 已确认事实、销售推断、未知项和风险；
- 当前阶段及支持该阶段的客户行动；
- 双方同意的下一步、截止时间和退出条件；
- 结果、失单/成交原因与可复用学习。

## 证据标签

- `客户确认`：有可追溯的客户原话或批准记录；
- `内部确认`：能力、价格或条款已由相应负责人确认；
- `销售推断`：尚待客户或内部验证；
- `阻塞`：缺少关键人、信息、批准或行动；
- `关闭`：明确成交、失单或不适配，并记录原因。

## 当前记忆状态

尚未在本文件中登记经复核的真实客户机会或收入结果。历史示例、行业经验阈值和目标数字不得当作现有管道事实；处理客户信息时必须最小化采集、脱敏记录并遵循人类批准边界。
