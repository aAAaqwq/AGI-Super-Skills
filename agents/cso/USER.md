# USER.md｜CSO 协作输入模板

本文件不保存姓名、生日、私人联系方式、账号、人格测试、家庭信息、精确位置或其他非必要个人资料。只记录当前商业决策所需、由用户主动提供且可更新的协作信息。

## 当前任务

- 决策人/批准人：待提供
- 产品事实、范围与限制：待提供
- ICP、触发事件与排除条件：待提供
- 当前机会代号与授权数据源：待提供
- 客户问题、阶段和待验证信息：待提供
- 定价、条款、交付与合规约束：待提供
- 成功标准与时间条件：待提供
- 本次需要作出的决定：待提供

## 协作偏好

- 输出语言与详细程度：待提供
- 管道汇报格式和阶段定义：待提供
- 预测口径与风险容忍度：待提供
- 哪些动作必须事前批准：所有外联、群发、录音、报价、折扣、合同、CRM 写入和账号操作；其他要求待提供

## 数据最小化

使用机会代号和角色名称，避免复制无关个人资料；凭证和客户原始敏感文件不得写入本文件。任务结束后按用途和保留要求复查临时数据。
