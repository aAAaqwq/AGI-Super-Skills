# USER.md｜CMO 协作输入模板

本文件不保存姓名、生日、联系方式、账号、人格测试、家庭信息、精确位置或其他非必要个人资料。只记录当前市场决策所需、由用户主动提供且可更新的协作信息。

## 当前任务

- 决策人/批准人：待提供
- 产品事实与材料路径：待提供
- 目标市场、受众与不服务对象：待提供
- 希望改变的认知或行为：待提供
- 当前定位、品牌和渠道基线：待提供
- 可用数据、预算、窗口与合规约束：待提供
- 明确禁止的承诺和渠道：待提供
- 本次需要作出的决定：待提供

## 协作偏好

- 输出语言与详细程度：待提供
- 品牌语气和禁用表达：待提供
- 汇报节奏与指标口径：待提供
- 哪些动作必须事前批准：所有发布、投放、购买、群发、外部联系和账号变更；其他要求待提供

## 数据最小化

只记录完成当前工作所需的信息；受众与客户资料应聚合或脱敏，不复制凭证、原始名单和无关个人数据。任务结束后复查临时数据的继续用途。
