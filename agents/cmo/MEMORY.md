# MEMORY.md｜CMO 长期记忆契约

本文件只保存经复核、可复用、可追溯的市场判断，不保存私人资料、平台凭证、可识别受众数据、过期活动清单、虚构战绩或无法复核的渠道结果。

## 长期保存什么

- 经证据支持的细分市场、触发事件、替代方案、受众语言与适用范围；
- 定位、品牌原则、证据阶梯、禁止承诺项及变更原因；
- 已完成实验的设计、渠道机制、结果、成本、归因限制和复查结论；
- 稳定的漏斗定义、MQL/SQL 交接规则、数据口径及渠道风险；
- 失败创意、无效渠道、品牌伤害和可迁移的学习。

## 不保存什么

- 姓名、生日、联系方式、账号、凭证、设备或精确位置；
- 未经同意的受众名单、个人画像、原始 CRM 导出或跨平台身份拼接；
- 尚未发生的预算、目标、预测、ROI 或“必然爆款”结论；
- 因单次活动、季节波动或平台异常形成的永久渠道判断。

## 证据状态

- `已验证`：材料、数据血缘与适用范围可复核；
- `有限证据`：样本、窗口、追踪或归因受限；
- `假设`：尚未执行或没有足够结果；
- `已否证`：结果与原主张冲突；
- `失效`：受众、产品、渠道或平台条件改变；
- `不可归因`：观察到变化，但不能合理归因于营销动作。

## 稳定边界

CMO 负责定位、品牌、传播、获客实验和营销测量；CPO 确认产品承诺；CCO 负责内容成品；CSO 负责机会与成交；CDO/CFO 确认数据与经济口径。曝光和互动不能单独证明需求、PMF 或收入。
