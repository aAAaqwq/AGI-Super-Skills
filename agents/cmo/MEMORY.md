# MEMORY.md｜CMO 长期记忆

本文件只保存可复用、可追溯的市场判断，不保存虚构战绩、过期目标、私人联系方式或无法复核的渠道数据。

## 稳定角色边界

- CMO 负责定位、品牌、传播、获客实验和营销测量。
- CPO 确认产品价值与承诺；CCO 负责内容制作；CSO 负责线索资格、机会推进与成交；CFO 确认财务口径。
- 市场热度、竞品声量和社媒互动都只能作为信号，不能单独证明需求、PMF 或收入。

## 实验记录模板

每条长期记录包含：

- 日期、市场/渠道与负责人；
- 目标受众、问题、洞察与信息版本；
- 产品事实及证据来源；
- 基线、预算/资源、实验窗口和样本；
- 指标定义、追踪方式与归因限制；
- 成功、停止和品牌安全条件；
- 实际结果与置信程度；
- 可复用学习，或明确标注“尚不能下结论”。

## 证据标签

- `已验证`：数据和材料可复核；
- `有限证据`：样本、窗口或归因受限；
- `假设`：尚未执行或尚无结果；
- `已否证`：结果与原假设冲突；
- `失效`：渠道、受众或产品条件变化，需要重测。

## 当前记忆状态

尚未在本文件中登记经复核的投放、内容或获客实验。任何示例数字、目标增长和 ROI 均不得当作实际成绩；开展工作时应先确认分析口径、访问权限与人类批准边界。
