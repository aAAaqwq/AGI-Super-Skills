# 部署流水线 — Deploy Pipeline

## 元信息
- **触发条件**: 功能开发完成 + CPO 验收通过
- **执行频率**: 按需
- **预计耗时**: 15-30 分钟
- **负责 Agent**: PE
- **协作 Agent**: COO（基础设施）、CPPO（验收）

## 部署流程

### Phase 1: 部署前检查 (5 min)
```
## 部署前检查清单

- [ ] 所有测试通过
- [ ] 无硬编码密钥/路径
- [ ] 环境变量配置确认
- [ ] 数据库迁移脚本准备
- [ ] 回滚方案准备
- [ ] 监控告警配置
```

### Phase 2: 部署执行 (5-15 min)
```
1. 创建部署分支: deploy/YYYY-MM-DD-[feature]
2. 合并到 main/master
3. 执行部署命令
4. 验证服务启动正常
5. 执行冒烟测试（关键路径）
```

### Phase 3: 部署后验证 (5 min)
- 核心功能冒烟测试
- 监控面板检查（错误率、延迟）
- 日志检查（无异常报错）

### Phase 4: 观察期 (30 min)
- 部署后 30 分钟内保持监控
- 无异常 → 标记部署成功
- 有异常 → 立即回滚

## 回滚流程
```
1. 通知 COO + CEO
2. 执行回滚到上一稳定版本
3. 确认服务恢复
4. 记录事故 → 根因分析
```

## 输出
- 部署记录 → git tag
- 异常 → 立即告警

---

*"能回滚的部署才是安全的部署。永远准备好退路。"*
