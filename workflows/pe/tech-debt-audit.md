# 技术债审计 — Tech Debt Audit

## 元信息
- **触发条件**: 每周日 15:00
- **执行频率**: 每周
- **预计耗时**: 20 分钟
- **负责 Agent**: PE

## 执行步骤

### Step 1: 债务盘点 (10 min)
扫描所有项目的技术债：

```
## 技术债周报 (YYYY-WW)

### 债务清单
| # | 项目 | 类型 | 描述 | 严重度 | 修复成本 |
|---|------|------|------|--------|----------|
| 1 | MediaClaw | 硬编码 | API URL 硬编码 | 🔴 高 | 30min |
| 2 | super-quant | TODO | 未处理的边界条件 | 🟡 中 | 1h |
| 3 | workspace | 过期依赖 | v2.x → v3.x | 🟡 中 | 2h |
```

**债务类型:**
- 硬编码/魔法数字
- 未处理的 TODO（> 1 周）
- 过期依赖
- 缺少测试
- 代码重复
- 性能瓶颈
- 文档缺失

### Step 2: 优先级排序 (5 min)
按 `严重度 × 影响范围 / 修复成本` 排序

### Step 3: 制定偿还计划 (5 min)
```
## 本周偿还计划
| 债务 | 预计时间 | 优先级 |
|------|----------|--------|
| #1 | 周一 30min | P1 |
| #3 | 周三 2h | P2 |
```

## 原则
- **每周至少还 1 笔技术债**，不让债务滚雪球
- **P0 债务当日还**（安全/正确性问题）
- **P1 债务本周还**（影响效率的问题）
- **P2 债务排期还**（优化类）

## 输出
- 技术债报告 → CEO
- 本周偿还任务 → 加入日常计划

---

*"技术债就像信用卡：借了就得还，不还利息比本金更贵。每周还一点，永远不欠债。"*
