# 每日盈亏 — Daily P&L

## 元信息
- **触发条件**: 每日定时 (21:00 CST)
- **执行频率**: 每天
- **预计耗时**: 10 分钟
- **负责 Agent**: CFO

## 执行步骤

### Step 1: 收集数据 (3 min)
拉取当日所有成本数据：
- API 调用费用（按 provider 分）
- 平台订阅费（按月分摊到日）
- 服务器/基础设施成本
- 其他运营支出

### Step 2: 计算盈亏 (5 min)
```
## 每日盈亏 (YYYY-MM-DD)

### 支出
| 类别 | 金额 | 占比 | vs 昨日 |
|------|------|------|---------|
| API 费用 | $X.XX | X% | +/-X% |
| 基础设施 | $X.XX | X% | — |
| 其他 | $X.XX | X% | — |
| **合计** | **$X.XX** | | |

### 收入
| 来源 | 金额 | 备注 |
|------|------|------|
| 内容收入 | $X.XX | 平台分成 |
| 产品收入 | $X.XX | 付费功能 |
| **合计** | **$X.XX** | |

### 净值: $X.XX (盈/亏)
```

### Step 3: 趋势分析 (2 min)
- 连续 3 天支出上升 → 标记 🟡
- 单日支出超过日均 200% → 标记 🔴
- API 成本异常 → 追踪具体 provider/agent

## 输出
- 每日盈亏报告 → CEO + 群
- 异常告警 → 即时

## 异常处理
- 成本飙升 → 追踪到具体 Agent/任务 → 通知相关负责人
- 余额不足 → 通知 CEO 充值
