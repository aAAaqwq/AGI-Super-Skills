# 成本优化扫描 — Cost Optimization

## 元信息
- **触发条件**: 每周一 10:00
- **执行频率**: 每周
- **预计耗时**: 20 分钟
- **负责 Agent**: CFO
- **协作 Agent**: PE（技术优化）、COO（基础设施）

## 执行步骤

### Step 1: 成本审计 (8 min)
拉取上周全量成本数据，按维度拆分：
- **按 Provider**: 哪个 API 最贵？能否换便宜模型？
- **按 Agent**: 哪个 Agent 消耗最多？是否有浪费？
- **按任务类型**: 内容/研究/开发各占多少？

### Step 2: 优化建议 (8 min)
针对 Top 3 成本项给出具体建议：

```
## 优化建议

### 1. [成本项]
- **现状**: $X.XX/周
- **原因**: [为什么贵]
- **方案**: [具体怎么做]
- **预期节省**: X%
- **风险**: [有什么代价]
- **执行人**: [谁来做]
```

### Step 3: 模型路由审查 (4 min)
检查当前模型配置：
- 是否有能用免费/低成本模型的任务在用昂贵模型？
- Fallback 配置是否合理？
- 是否有重复调用可缓存？

## 输出
- 成本审计报告 → CEO
- 优化建议列表（优先级排序）
