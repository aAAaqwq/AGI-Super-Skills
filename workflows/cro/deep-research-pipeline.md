# 深度研究管线 — Deep Research Pipeline

## 元信息
- **触发条件**: CEO 派发研究任务 / 周度研究计划
- **执行频率**: 每周 1-2 个深度研究
- **预计耗时**: 2-4 小时/主题
- **负责 Agent**: CRO

## 执行步骤

### Phase 1: 研究设计 (15 min)
```
## 研究计划: [主题]

### 研究问题
1. [主问题]
2. [子问题]

### 信息源
- [数据源 1] — [获取方式]
- [数据源 2] — [获取方式]

### 输出格式
- [最终产出物及格式]
```

### Phase 2: 信息采集 (1-2h)
- 搜索 + 筛选 + 交叉验证
- 收集至少 5 个可信来源
- 标注信息时效性

### Phase 3: 分析与综合 (1-2h)
- 数据整理与对比
- 模式识别与趋势判断
- 量化结论（有数字支撑）

### Phase 4: 报告输出 (30 min)
```
## 研究报告: [主题]

### TL;DR (3 句话)
[核心结论]

### 背景
[为什么研究这个]

### 发现
1. [发现 1] — [数据支撑]
2. [发现 2] — [数据支撑]

### 建议
1. [行动建议] — [预期收益] — [执行难度]
```

## 输出
- 研究报告 → `reports/` 目录
- 关键发现 → 即时通知 CEO

## 质量门禁
- [ ] 至少 5 个来源交叉验证
- [ ] 每个结论有数据支撑
- [ ] TL;DR 可独立阅读
- [ ] 有可执行的建议
