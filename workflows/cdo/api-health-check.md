# API 健康检查 — API Health Check

## 元信息
- **触发条件**: 每日定时 (09:30 CST)
- **执行频率**: 每天
- **预计耗时**: 5 分钟
- **负责 Agent**: CDO

## 执行步骤

### Step 1: 端点检查 (3 min)
对所有关键 API 执行健康检查：

```
| 服务 | 端点 | 状态 | 延迟 | 额度剩余 |
|------|------|------|------|----------|
| OpenAI | /v1/models | ✅ | 230ms | $12.50 |
| Gemini | /generate | ✅ | 180ms | 85% |
```

### Step 2: 额度预警
- 额度 < 20% → 🟡 通知 CEO
- 额度 < 5% → 🔴 P1，立即通知 CEO + 安排充值
- 额度 = 0 → 🔴 P0，切换 fallback 模型

### Step 3: Key 轮换检查
- 检查是否有即将过期的 API key（7 天内）
- 有则通知 CEO 安排轮换

## 输出
- 健康报告（≤ 5 行）
- 异常告警（即时）
