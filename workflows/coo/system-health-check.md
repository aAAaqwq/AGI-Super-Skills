# 系统健康巡检 — System Health Check

## 元信息
- **触发条件**: 每日 08:00 CST
- **执行频率**: 每天
- **预计耗时**: 8 分钟
- **负责 Agent**: COO

## 执行步骤

### Step 1: 基础设施检查 (3 min)
```
## 系统巡检 (YYYY-MM-DD)

### 服务状态
| 服务 | 状态 | CPU | 内存 | 磁盘 | 延迟 |
|------|------|-----|------|------|------|
| OpenClaw Gateway | ✅ | 12% | 45% | 23% | — |
| Freqtrade Bot 1 | ✅ | 8% | 2.1G | — | — |
| Freqtrade Bot 2 | ✅ | 6% | 1.8G | — | — |
```

### Step 2: Cron 任务检查 (3 min)
```
### Cron 任务
| 任务 | 频率 | 昨次执行 | 状态 | 耗时 |
|------|------|----------|------|------|
| 市场晨报 | 每天 08:00 | 08:00 | ✅ | 12s |
| 内容采集 | 每小时 | 14:00 | ❌ | 超时 |
```

### Step 3: 安全检查 (2 min)
- OpenClaw API key 轮换状态
- 系统异常登录/访问
- 磁盘空间预警（>80%）

## 告警规则
- 服务宕机 → 🔴 P0
- Cron 失败 > 3 次 → 🟡 P1
- CPU/内存 > 90% → 🟡 P1
- 磁盘 > 80% → 🟡 P1, > 90% → 🔴 P0

## 输出
- 巡检报告 → CEO（异常才发，正常不发）
