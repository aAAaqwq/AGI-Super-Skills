# 获客漏斗巡检 — Lead Funnel Check

## 元信息
- **触发条件**: 每日 10:00 CST
- **执行频率**: 每天
- **预计耗时**: 8 分钟
- **负责 Agent**: CSO

## 执行步骤

### Step 1: 漏斗数据 (5 min)
```
## 获客漏斗 (YYYY-MM-DD)

| 阶段 | 今日 | 昨日 | 周均 | 转化率 |
|------|------|------|------|--------|
| 曝光 | X | X | X | — |
| 点击 | X | X | X | X% |
| 注册 | X | X | X | X% |
| 活跃 | X | X | X | X% |
| 付费 | X | X | X | X% |
```

### Step 2: 异常标记 (3 min)
- 转化率骤降（> 20%）→ 检查对应环节
- 新增线索增加 > 50% → 检查来源是否可持续
- 付费转化变化 → 关联最近改动

## 输出
- 漏斗报告 → CEO（异常才发）
