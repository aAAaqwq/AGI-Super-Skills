# 合规巡检 — Compliance Audit

## 元信息
- **触发条件**: 每周一 11:00
- **执行频率**: 每周
- **预计耗时**: 20 分钟
- **负责 Agent**: CLO

## 执行步骤

### Step 1: API Key 审计 (5 min)
- 检查所有 API key 有效期
- 检查是否有 key 在非预期环境使用
- 检查权限范围是否最小化

### Step 2: 数据合规 (5 min)
- 检查是否有敏感数据写入日志/仓库
- 检查 `agents/` 去敏状态（super-team 仓库）
- 检查 `.gitignore` 覆盖范围

### Step 3: 平台合规 (5 min)
- 内容发布是否遵守各平台规则
- 是否有版权风险
- 用户数据处理是否合规

### Step 4: 报告 (5 min)
```
## 合规周报 (YYYY-WW)

| 检查项 | 状态 | 发现 |
|--------|------|------|
| API Key 轮换 | ✅ | 全部有效 |
| 数据去敏 | ⚠️ | [发现] |
| 平台合规 | ✅ | — |
```

## 输出
- 合规报告 → CEO
- 发现项 → 通知相关 Agent 修复
